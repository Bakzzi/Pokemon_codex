# run-buddy — 디지몬 어드벤처 편

Claude Code 입력창 바로 위에서 내 디지몬이 어드벤처의 빌런과 싸웁니다. 작업 상태, 사용 한도(HP), 레벨, 이달의 문장을 한눈에 보여 줍니다.
매달 선택받은 아이들의 문장 8개 가운데 하나가 뽑히고, 그 파트너 디지몬이 레벨에 따라 유년기부터 궁극체까지 진화합니다.

원본 run-buddy(모험가·기사 같은 직업과 장비)의 캐릭터만 디지몬으로 바꾼 판입니다. 시즌·경험치·보물상자·펫은 그대로입니다.

## 화면

- **일하는 동안**: 내 디지몬이 레벨에 맞는 상대와 싸우고, 데미지 숫자가 뜹니다. 공격 순간에는 몸을 움찔하며 입(손)에서 고유 기술이 나가고,
  근접 기술(카이저 네일·글러브 펀치·해머 스파크·캣 펀치)은 돌진해 칩니다. 머리 위에는 HP 이름표(5시간·주간 한도의 남은 비율)와 레벨 배지가 붙습니다.
  경과 시간은 앱의 진행 표시줄이 보여 주고, 그 뒤에 "필살기 모으는 중" 같은 한마디가 붙습니다.
- **일이 끝나면**: 디지몬이 확 커지면서 말풍선이 뜹니다. "다 했어요! 결과 확인해 주세요"
- **기다릴 때**: 사람에게 묻는 권한 요청(1.5초 넘게), 질문, 계획 승인을 기다리면 손을 들고 "잠깐만요!"라고 알립니다.
  자동 모드에서 분류기가 정하는 권한 확인은 알리지 않습니다.
- **오류로 멈추면**: 색이 바랜 채 비틀거리며 "멈췄어요!"라고 알립니다.
- **쉬는 동안**: 왼쪽에 지금 진화 단계의 디지몬, 오른쪽에 HP 막대 두 줄(회복 시각 포함)과 레벨·경험치 줄을 보여 줍니다.

끝·오류 알림은 다음 지시를 보내거나 **확인**을 누르면 사라집니다. Esc로 직접 멈춘 턴은 알리지 않습니다.

## 레벨

- 경험치 = 주간 한도 사용률(%). **2주 동안 매주 한도를 다 쓰면 200 XP = Lv.100** (2 XP마다 1레벨)
- 한 시즌은 **한 달**(한국 시간 1일 0시부터). 달이 바뀌면 Lv.1부터 다시 시작합니다.
- 달 중간에 설치해도 **1일부터 쓴 양**으로 시작합니다. 설치할 때 `node scripts/seed.mjs`로 로컬 대화 기록의 시간별 사용량을
  모아 두면(`hooks/seed.ts`), 이번 주 실제 사용률과 비교해 이번 달 지난 주들의 사용률을 어림합니다(24시간 안에 불러와야 반영).
  기록이 없으면 이번 주 사용량부터 셉니다. 이번 주가 지난달에 시작했으면 지난 시간에 비례해 이번 달 몫만 셉니다.
- 한도는 계정 전체 값이라 모든 세션(창)이 기록 하나를 같이 씁니다. 같은 주의 사용량을 두 번 세지 않습니다.
  창마다 본 한도도 함께 모아 두고, 쉬고 있는 창은 1분마다 그 기록을 읽어 레벨과 HP를 맞춥니다.
- 상대의 체력 막대 = 다음 기술·진화까지 남은 경험치. 10레벨마다 상대를 쓰러뜨리고 기술이나 진화를 얻으며, 알림 팝업이 뜹니다.

| 레벨 | 상대 | 내 디지몬 |
| --- | --- | --- |
| 1~9 | 워매몬 | 유년기 |
| 10~19 | 데블몬 | 성장기 (Lv.10 진화) |
| 20~29 | 에테몬 | 성장기 (Lv.20 기술) |
| 30~39 | 묘티스몬 | 성장기 (Lv.30 단련) |
| 40~49 | 베놈묘티스몬 | 성숙기 (Lv.40 진화) |
| 50~59 | 메탈시드라몬 | 성숙기 (Lv.50 기술) |
| 60~69 | 피노키몬 | 완전체 (Lv.60 초진화) |
| 70~79 | 묵시몬 | 완전체 (Lv.70 기술) |
| 80~89 | 피에몬 | 완전체 (Lv.80 기술) |
| 90~99 | 아포카리몬 | 궁극체 (Lv.90 궁극진화, 후광) |
| 100 | 오메가몬이 동료로 합류 | 궁극체 (무지개 후광) |

## 문장과 진화 계열

디지몬 이름은 한국판 더빙 명칭(파피몬·쉬라몬·원뿔몬·워매몬 등)을 씁니다.

매달 1일 새 시즌에 이달의 문장이 하나 뽑힙니다. 8가지가 겹치지 않게 돌고, 8개를 다 돌면 새로 섞습니다.
지난달 문장은 다음 달에 나오지 않습니다. 달 이름으로 섞어 고르므로 모든 창에서 같은 문장이 나옵니다.

| 문장 | 유년기 → 성장기 → 성숙기 → 완전체 → 궁극체 | 대표 기술 (hooks/fx.ts) |
| --- | --- | --- |
| 용기 | 코로몬 → 아구몬 → 그레이몬 → 메탈그레이몬 → 워그레이몬 | 거품 → 꼬마불꽃(주황 불덩이) → 큰불꽃 → 기가 디스트로이어(가슴 미사일 2)·트라이던트 암 → 테라 포스(머리 위 큰 불 에너지구) |
| 우정 | 원뿔몬 → 파피몬(가브몬) → 가루몬 → 워가루몬 → 메탈가루몬 | 거품 → 파란불꽃 → 폭스 파이어(큰 파란 불꽃) → 카이저 네일(발톱, 근접) → 코큐토스 브레스(얼음 빔) |
| 사랑 | 뿌카몬 → 피요몬 → 버드라몬 → 가루다몬 → 피닉스몬 | 거품 → 매지컬 파이어(초록 불꽃) → 메테오 윙(떨어지는 불덩이) → 섀도우 윙(큰 불덩이)·이글 클로 → 스타라이트 익스플로전(별 비) |
| 순수 | 타네몬 → 팔몬 → 니드몬 → 릴리몬 → 로제몬 | 거품 → 포이즌 아이비(덩굴) → 니들 스프레이(가로 바늘) → 플라워 캐논(꽃 포탄) → 템프테이션(채찍) |
| 지식 | 모티몬 → 텐타몬 → 캅테리몬 → 메가캅테리몬 → 헤라클레스캅테리몬 | 거품 → 쁘띠 썬더(파란 전기 불꽃) → 일렉트로 쇼커(파란 전기구) → 호른 버스터(전기 빔) → 메가 블래스터·울트라 썬더(번개) |
| 성실 | 푸카몬 → 쉬라몬 → 이크몬 → 쥬드몬 → 플레시오몬 | 거품 → 마칭 피시즈(색색의 물고기 떼) → 하푼 발칸(뿔 작살) → 해머 스파크(망치, 근접+번개) → 소로 블루(물 빔) |
| 희망 | 토코몬 → 파닥몬 → 엔젤몬 → 홀리엔젤몬 → 세라피몬 | 거품 → 공기팡(바람 고리) → 천사의 화살(금빛 화살) → 헤븐즈 게이트(빛기둥)·엑스칼리버 → 세븐 헤븐즈(빛구 7개) |
| 빛 | 뉴몬 → 플롯몬 → 가트몬 → 엔젤우몬 → 오파니몬 | 거품 → 퍼피 하울링(흰 음파) → 냥냥펀치(발톱, 근접) → 성스러운 화살(분홍 화살)·헤븐즈 참 → 에덴즈 재블린(창 던지기+빛기둥) |

계열마다 10레벨마다 얻는 기술 이름이 다릅니다(`hooks/jobs/*.ts`의 `gear`). 디지몬별 기술 효과·근접 여부·발사 위치(`mouth`)는 `preview/gen-lines.py`의 표에서 정하고, 원거리 디지몬은 서 있는 그림 그대로 움찔하며 입(손)에서 기술을 쏩니다.
기술 효과 그림은 `hooks/fx.ts`의 벡터 원화를 `preview/build-fx.sh`가 1칸당 4점 도트 PNG로 구워(`sprites/fx/`, `hooks/img/fx.ts`) 스프라이트와 같은 도트 느낌으로 보입니다. 레벨 90에는 후광, 레벨 100에는 무지개 후광이 붙습니다.

## 그림 출처와 손보기

- 디지몬·빌런 그림은 [위키몬](https://wikimon.net)에 올라온 디지몬 서바이브(2022)의 전투 일러스트가 기본이고, 서바이브에 없는 유년기·플롯몬·오파니몬·데블몬·베놈묘티스몬·아포카리몬은 디지몬 뉴 센추리·공식 설정화·DMO 그림입니다. 모두 비스듬히(45도) 적을 봅니다.
  (`sprites/<묶음>/*.png`). 반다이남코의 저작물이므로 개인 사용 범위에서만 쓰세요.
- `preview/prep-art.py`가 큰 일러스트를 높이 160px로 줄이고, `preview/pixelate-all.py`가 화면 크기에 맞춰 1칸당 4점의 도트 그림(32색, 옆 색을 어둡게 한 1점 테두리)으로 바꾸며, `preview/embed.py`가 `hooks/img/*.ts`에 base64로 심습니다. 화면에서는 점을 그대로 키웁니다(image-rendering: pixelated).
  그림을 바꾸려면 PNG를 `sprites/` 아래에 넣고 `python3 preview/embed.py <묶음>`을 다시 실행하세요.
- `preview/render-all.sh`로 모든 계열의 화면을 `preview/out/`에 PNG로 뽑아 볼 수 있습니다(node 22, cairosvg, Pillow 필요).

## 보물상자와 펫

일을 잘 마칠 때마다(오류·Esc 제외) 1% 확률로 끝 알림에 보물상자가 나옵니다. 한 달에 한 번까지만 나옵니다.
**확인**을 누르면 상자가 열리고 고양이·강아지·아기 드래곤·엘리멘탈 가운데 하나가 튀어나와, 그달 내내 내 디지몬 뒤를 따라다닙니다
(전투·쉬는 띠·끝 알림 모두). 능력은 없는 치장 동료이고, 새 달이 되면 다시 상자를 찾아야 합니다.
다른 창에서 찾은 상자는 1분 안에 쉬는 띠에 나오고, **열기** 버튼으로 엽니다.

## 알아 둘 점

- 데스크톱 앱은 입력창 위 띠를 화면 분할의 **첫 번째(맨 왼쪽) 칸**에서만 그립니다(앱 제한). 다른 칸에서는 진행 표시줄의 한마디만 보입니다.
  다른 칸에서 일한 만큼의 경험치와 HP는 1분 안에 왼쪽 칸에 반영됩니다.
- 구독 한도 정보가 없는 계정에서는 HP와 레벨을 표시하지 않습니다.

## 설치

1. `run-buddy` 폴더를 `~/.claude/mods/run-buddy`에 둡니다.
2. `~/.claude/settings.json`의 `"env"`에 넣습니다(다른 내용은 그대로 두고 이 줄만 추가).

   ```json
   "env": {
     "CLAUDE_CODE_PLUGIN_DIRS": "C:\\Users\\<사용자이름>\\.claude\\mods\\run-buddy",
     "CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1"
   }
   ```

3. 이번 달 사용량을 모읍니다(선택, node 필요): `node ~/.claude/mods/run-buddy/scripts/seed.mjs`
4. 바로 `/reload-plugins`를 입력하거나 Claude 데스크톱 앱을 다시 시작합니다.

## 끄기

settings.json의 `CLAUDE_CODE_PLUGIN_DIRS`에서 run-buddy 경로를 지우고 앱을 다시 시작합니다.

## 테스트

```bash
claude plugin test <run-buddy 폴더>
```

원본은 Claude Code 2.1.293에서 만들고 테스트했습니다. 디지몬 판은 2.1.296에서 미리보기 렌더링으로만 확인했습니다.
