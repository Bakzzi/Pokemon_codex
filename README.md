# run-buddy — 디지몬 어드벤처 편

Claude Code 입력창 바로 위에서 내 디지몬이 디지몬 어드벤처의 빌런과 싸웁니다. 작업 상태, 사용 한도(HP), 레벨, 이달의 계열을 한눈에 보여 줍니다.
매달 선택받은 아이들의 문장 8개 가운데 하나가 뽑히고, 그 파트너 디지몬이 레벨에 따라 유년기부터 궁극체까지 진화합니다.

원본 run-buddy(모험가·기사 같은 직업과 장비)의 캐릭터·상대·기술 연출을 디지몬으로 바꾼 판입니다. 시즌·경험치 체계는 그대로이고, 보물상자·펫은 디지바이스 임시 진화로 바꿨습니다.
개인 사용 목적으로 만든 모드입니다.

## 화면

- **일하는 동안**: 내 디지몬이 레벨에 맞는 상대와 싸우고, 데미지 숫자가 뜹니다. 공격 순간에는 몸을 움찔하며 입(손·뿔)에서 고유 기술이 나가고,
  근접 기술(카이저 네일·해머 스파크·냥냥펀치)은 돌진해 칩니다. 머리 위에는 HP 이름표(5시간·주간 한도의 남은 비율)와 레벨 배지가 붙습니다.
  경과 시간은 앱의 진행 표시줄이 보여 주고, 그 뒤에 "필살기 모으는 중" 같은 한마디가 붙습니다.
- **일이 끝나면**: 디지몬이 확 커지면서 말풍선이 뜹니다. "다 했어요! 결과 확인해 주세요"
- **기다릴 때**: 사람에게 묻는 권한 요청(1.5초 넘게), 질문, 계획 승인을 기다리면 "잠깐만요!"라고 알립니다.
  자동 모드에서 분류기가 정하는 권한 확인은 알리지 않습니다.
- **오류로 멈추면**: 지금 상대가 고유 기술로 내 디지몬을 치고(근접이면 달려들고), "○○의 △△! 문제가 생겼어요"라고 알립니다. 3.6초마다 반복합니다.
- **쉬는 동안**: 왼쪽에 지금 진화 단계의 디지몬, 오른쪽에 HP 막대 두 줄(회복 시각 포함)과 레벨·경험치 줄을 보여 줍니다.

끝·오류 알림은 다음 지시를 보내거나 **확인**을 누르면 사라집니다. Esc로 직접 멈춘 턴은 알리지 않습니다.

## 레벨과 상대

- 경험치 = 주간 한도 사용률(%). **2주 동안 매주 한도를 다 쓰면 200 XP = Lv.100** (2 XP마다 1레벨)
- 한 시즌은 **한 달**(한국 시간 1일 0시부터). 달이 바뀌면 Lv.1부터 다시 시작합니다.
- 달 중간에 설치해도 **1일부터 쓴 양**으로 시작합니다. 설치할 때 `node scripts/seed.mjs`로 로컬 대화 기록의 시간별 사용량을
  모아 두면(`hooks/seed.ts`), 이번 주 실제 사용률과 비교해 이번 달 지난 주들의 사용률을 어림합니다(24시간 안에 불러와야 반영).
  기록이 없으면 이번 주 사용량부터 셉니다. 이번 주가 지난달에 시작했으면 지난 시간에 비례해 이번 달 몫만 셉니다.
- 한도는 계정 전체 값이라 모든 세션(창)이 기록 하나를 같이 씁니다. 같은 주의 사용량을 두 번 세지 않습니다.
  창마다 본 한도도 함께 모아 두고, 쉬고 있는 창은 1분마다 그 기록을 읽어 레벨과 HP를 맞춥니다.
- 상대의 체력 막대 = 다음 기술·진화까지 남은 경험치. 10레벨마다 상대를 쓰러뜨리고 기술이나 진화를 얻으며, 알림 팝업이 뜹니다.
  Lv.100의 최종 보스는 체력이 줄지 않고 시즌이 끝날 때까지 결전을 벌입니다.

| 레벨 | 상대 (단계) | 내 디지몬 (단계) |
| --- | --- | --- |
| 1~9 | 워매몬 (성숙기) | 유년기 |
| 10~19 | 우가몬 (성숙기) | 성장기 (Lv.10 진화) |
| 20~29 | 데블몬 (성숙기) | 성장기 (Lv.20 기술) |
| 30~39 | 에테몬 (완전체) | 성숙기 (Lv.30 진화) |
| 40~49 | 묘티스몬 (완전체) | 성숙기 (Lv.40 기술) |
| 50~59 | 베놈묘티스몬 (궁극체) | 완전체 (Lv.50 초진화) |
| 60~69 | 메탈시드라몬 (궁극체) | 완전체 (Lv.60 기술) |
| 70~79 | 피노키몬 (궁극체) | 완전체 (Lv.70 기술) |

| 90~99 | 피에몬 (궁극체) | 궁극체 (Lv.90 기술 강화: 1.3배) |
| 100 | 아포카리몬 (궁극체, 최종 보스) | 궁극체 (Lv.100 기술 극대화: 1.6배) |

상대의 기술(오류 알림에서 씀): 워매몬 똥 던지기 · 우가몬 몽둥이 찍기 · 데블몬 데스 클로 · 에테몬 러브 세레나데 · 묘티스몬 크림슨 라이트닝 · 베놈묘티스몬 베놈 인퓨즈 ·
메탈시드라몬 용의 콧물 · 피노키몬 불릿 해머 · 파워드라몬 무한 캐논 · 피에몬 트럼프 소드 · 아포카리몬 다크니스 존. `hooks/monsters.ts`의 `FOES` 표에서 바꿉니다.

상대는 애니 등장 순서 그대로라 내 디지몬보다 늘 한 단계쯤 위입니다(애니에서도 성장기들이 데블몬을, 완전체들이 4천왕을 상대했습니다).

**히든 진화 오메가몬**: 용기 시즌에서 워그레이몬(Lv.80), 우정 시즌에서 메탈가루몬(Lv.80)이 각각 한 번이라도 되면(다른 달이어도 됨) 그 뒤로는
어느 계열 시즌이든 Lv.100에 오메가몬으로 조그레스 진화해 아포카리몬과 싸웁니다(가루루 캐논 + 그레이 소드).
닿은 계열은 `$.store 'maxed'`에 남고, 둘 다 채우면 알림이 뜹니다.

## 문장과 진화 계열

디지몬·기술 이름은 한국판 더빙 명칭을 씁니다(파피몬·쉬라몬·뿔몬·원뿔몬·워매몬·우가몬·파워드라몬 등).

매달 1일 새 시즌에 이달의 문장(계열)이 하나 뽑힙니다. 8가지가 겹치지 않게 돌고, 8개를 다 돌면 새로 섞습니다.
지난달 계열은 다음 달에 나오지 않습니다. 달 이름으로 섞어 고르므로 모든 창에서 같은 계열이 나옵니다.

| 문장 | 유년기 → 성장기 → 성숙기 → 완전체 → 궁극체 | 기술 (한국판 더빙명, 연출) |
| --- | --- | --- |
| 용기 | 코로몬 → 아구몬 → 그레이몬 → 메탈그레이몬 → 워그레이몬 | 거품 → 꼬마 불꽃(불덩이) → 메가 파이어(큰 불덩이) → 인공지능 미사일(가슴 미사일 2)·왕발톱 → 테라 광선(머리 위 큰 에너지구) |
| 우정 | 뿔몬 → 파피몬 → 가루몬 → 워가루몬 → 메탈가루몬 | 거품 → 파란 불꽃 → 푸른 화염포(큰 파란 불꽃) → 초강력 손톱(발톱, 근접) → 썰렁포(얼음 빔) |
| 사랑 | 어니몬 → 피요몬 → 버드라몬 → 가루다몬 → 페닉스몬 | 거품 → 빙빙 회오리(초록 불꽃) → 메테오 윙(떨어지는 불덩이) → 불새 출격(큰 불덩이)·이글 클로 → 스타라이트 익스플로전(별 비) |
| 순수 | 시드몬 → 팔몬 → 니드몬 → 릴리몬 → 로제몬 | 거품 → 독줄기 공격(덩굴) → 바늘뿜기(바늘) → 플라워 캐논(꽃 포탄) → 릴리몬의 유혹(가시 채찍) |
| 지식 | 모티몬 → 텐타몬 → 캅테리몬 → 아트라캅테리몬 → 헤라클레스캅테리몬 | 거품 → 쁘띠 썬더(전기 불꽃) → 일렉트로 쇼커(전기구) → 혼 버스터(뿔 전기 빔) → 메가 블래스터·울트라 썬더(번개) |
| 성실 | 둥실몬 → 쉬라몬 → 원뿔몬 → 쥬드몬 → 바이킹몬 | 거품 → 물고기 행진(색색의 물고기 떼) → 뿔 날리기(뿔 작살) → 해머 스파크(망치, 근접+번개) → 아크틱 블리자드(철퇴, 근접) |
| 희망 | 토코몬 → 파닥몬 → 엔젤몬 → 홀리엔젤몬 → 세라피몬 | 거품 → 공기팡(바람 고리) → 천사의 손(주먹에서 금빛 빔) → 천국의 문(빛기둥)·엑스칼리버 → 세븐 헤븐즈(빛구 7개) |
| 빛 | 야옹몬 → 플롯몬 → 가트몬 → 엔젤우몬 → 오파니몬 | 거품 → 퍼피 하울링(음파) → 냥냥펀치(발톱, 근접) → 천국의 화살(분홍 화살)·천국의 미소 → 낙원의 창(창 던지기+빛기둥) |
| 조그레스 | 오메가몬 (히든) | 가루루 캐논(얼음 빔)·그레이 소드(베기) |

한국판 더빙명은 나무위키·위키백과에서 확인한 것(꼬마 불꽃, 메가 파이어, 인공지능 미사일, 왕발톱, 테라 광선, 파란 불꽃, 푸른 화염포, 썰렁포, 빙빙 회오리, 불새 출격, 독줄기 공격, 릴리몬의 유혹, 쁘띠 썬더, 혼 버스터, 물고기 행진, 뿔 날리기, 바늘뿜기(사용자 확인), 천사의 손, 천국의 문, 천국의 화살, 천국의 미소, 낙원의 창)을 쓰고,
한국판에 나오지 않았거나 확인하지 못한 기술(메테오 윙, 플라워 캐논, 일렉트로 쇼커, 해머 스파크, 공기팡, 냥냥펀치, 궁극체 기술)은 원어 또는 통용 이름입니다.
진화 계열과 이름은 나무위키 디지몬 어드벤처 진화 트리(한국판)를 따릅니다. 궁극체는 극장판·설정 기준(페닉스몬·로제몬·바이킹몬·세라피몬·오파니몬)입니다.

진화 구간은 성장기 Lv.10, 성숙기 Lv.30, 완전체 Lv.50, 궁극체 Lv.80이고, 레벨 90에는 기술이 1.3배(강화), 레벨 100에는 1.6배(극대화)로 커집니다.

## 그림 손보기

그림은 [위키몬](https://wikimon.net)에 올라온 디지몬 서바이브·뉴 센추리 등의 일러스트입니다. 반다이남코 저작물이므로 개인 사용 범위에서만 쓰세요.

1. **디지몬·상대 그림**: `art/<묶음>/<키>.png`를 바꾼 뒤 `python3 preview/pixelate-all.py` → 화면 크기에 맞춰 1칸당 4점·32색 도트로 바꿔 `sprites/`에 씁니다.
   이어서 `python3 preview/embed.py <묶음>`으로 `hooks/img/<묶음>.ts`에 심습니다. 화면에서는 점을 그대로 키웁니다(image-rendering: pixelated).
2. **진화 단계·키·방향·발사 위치·기술·근접 여부**: `preview/gen-lines.py`의 표(`LINES`, `FX`, `MELEE`, `OMEGA`)를 고치고 실행하면 `hooks/jobs/*.ts`가 다시 만들어집니다.
   `python3 preview/mouths.py preview/out/mouths.png`로 발사 위치를 그림 위에 점으로 찍어 확인할 수 있습니다.
3. **기술 효과 그림**: `hooks/fx.ts`의 `ARTS`를 고치고 `./preview/build-fx.sh` → 1칸당 4점 도트 PNG로 구워 `sprites/fx/`와 `hooks/img/fx.ts`에 넣습니다.
4. **미리보기**: `./preview/render-all.sh`(쉬는 모습·전투)와 `./preview/attack-sheet.sh`(공격 순간)가 `preview/out/`에 PNG를 만듭니다.
   node 22, cairosvg, Pillow가 필요합니다. 정지 화면이라 돌진·채찍처럼 움직이는 효과는 실제 앱에서만 보입니다.

## 디지바이스 (임시 진화)

일을 잘 마칠 때마다(오류·Esc 제외) 1% 확률로 끝 알림에 디지바이스가 나옵니다. 한 달에 한 번까지, 아직 궁극체가 아닐 때만 나옵니다.
**확인**을 누르면 디지바이스의 빛으로 한 진화 단계 위 모습이 되어 그달 남은 기간 동안 그 모습과 기술로 싸웁니다
(예: Lv.15 아구몬 → 그레이몬). 레벨·상대·경험치는 그대로이고, 레벨로 그 단계에 닿으면 자연히 흡수됩니다. 새 달이 되면 효과가 끝납니다.
다른 창에서 찾은 디지바이스는 1분 안에 쉬는 띠에 나오고, **진화** 버튼으로 씁니다. 모든 창이 `$.store 'digivice'` 하나를 같이 씁니다.

## 알아 둘 점

- 데스크톱 앱은 입력창 위 띠를 화면 분할의 **첫 번째(맨 왼쪽) 칸**에서만 그립니다(앱 제한). 다른 칸에서는 진행 표시줄의 한마디만 보입니다.
  다른 칸에서 일한 만큼의 경험치와 HP는 1분 안에 왼쪽 칸에 반영됩니다.
- 구독 한도 정보가 없는 계정에서는 HP와 레벨을 표시하지 않습니다.
- 그림이 base64로 코드에 들어 있어 `hooks/img/`가 약 340KB입니다.

## 설치

1. `run-buddy` 폴더를 원하는 곳에 둡니다(예: `~/.claude/mods/run-buddy`).
2. `~/.claude/settings.json`의 `"env"`에 넣습니다(다른 내용은 그대로 두고 이 줄만 추가).

   ```json
   "env": {
     "CLAUDE_CODE_PLUGIN_DIRS": "/home/<사용자이름>/.claude/mods/run-buddy",
     "CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1"
   }
   ```

   윈도우라면 `C:\\Users\\<사용자이름>\\.claude\\mods\\run-buddy` 처럼 적습니다.
3. 이번 달 사용량을 모읍니다(선택, node 필요): `node <run-buddy 폴더>/scripts/seed.mjs`
4. 바로 `/reload-plugins`를 입력하거나 Claude 데스크톱 앱을 다시 시작합니다.

## 끄기

settings.json의 `CLAUDE_CODE_PLUGIN_DIRS`에서 run-buddy 경로를 지우고 앱을 다시 시작합니다.

## 테스트

```bash
claude plugin test <run-buddy 폴더>
```

원본은 Claude Code 2.1.293에서 만들고 테스트했습니다. 디지몬 판은 2.1.296에서 미리보기 렌더링과 문법 검사(esbuild)로만 확인했고, 실제 앱 동작은 설치 후 확인이 필요합니다.
