모험의 발걸음

오늘 0걸음

함께 걸은 총 0걸음

켜 두면 모험하고, 꺼 두면 걸음 수를 모아요.

모험 설정

앱을 켜 두면 자동으로 모험해요. 다른 앱을 보거나 화면을 꺼도 10걸음마다 모험을 이어가요.

앱을 꺼 두면 10걸음마다 모험 행동 1회를 진행해요. 기록되지 않은 걸음 수와 대기 시간에는 보상이 없어요.

자동 업데이트

새 버전은 자동으로 확인하고 설치해요.
